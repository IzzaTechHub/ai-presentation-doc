# Project Architecture Overview

## Application Summary
Flutter application providing AI-assisted presentation and document generation workflows.

## Directory Structure
- [lib/main.dart](file:///e:/Abdulrahman/imagineX/lib/main.dart): Application bootstrap and entrypoint.
- [lib/models/](file:///e:/Abdulrahman/imagineX/lib/models/): Data models and serialization logic.
- [lib/screens/](file:///e:/Abdulrahman/imagineX/lib/screens/): Presentation UI screens and page flows.
- [lib/services/](file:///e:/Abdulrahman/imagineX/lib/services/): API communications and device services.
- [lib/widgets/](file:///e:/Abdulrahman/imagineX/lib/widgets/): Reusable UI widgets and presentation components.

## Target Platforms
- Android, iOS, Web, Windows, macOS, Linux.
